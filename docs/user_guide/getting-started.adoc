== Getting started
ifndef::monolith[]
toc::[]
endif::monolith[]

Download latest release from here: https://github.com/esmini/esmini/releases/latest

First time make sure to pick the demo package for your platform (Windows, Linux or Mac), e.g. `esmini-demo_Windows.zip`, `esmini-demo_Linux.zip`, or `esmini-demo_macOS.zip`. In addition to application binaries it also includes some content like example scenarios and basic 3D models. The binary (bin) packages include only executables and libraries.

On Windows, make sure the zip file is not blocked: Right click, click Properties, at bottom right check Unblock. For more info, see link:support-qa.html#_blocked_by_windows_defender_smartscreen[Blocked by Windows Defender SmartScreen].

To install the demo package, just unzip it anywhere. A single subfolder named `esmini-demo` is created. This is the root folder for the demo. No files are stored outside this folder structure and no system files or registry is modified in any way.

=== Run esmini

Try to run one of the examples:

* go to folder `esmini-demo/run/esmini`
* double click on a .bat file, e.g. `run_cut-in.bat` or run it from a command line.

These scripts should work on all platforms (in spite of the extension ".bat").

You can also run the examples explicitly from a command line (from the `esmini-demo` root folder):

``./bin/esmini --window 60 60 800 400 --osc ./resources/xosc/cut-in.xosc``

For common Mac issues, please see link:support-qa.html#_mac_issues_and_limitations[Mac issues and limitations].

=== Get complete esmini
The demo package contains only a subset of esmini tools and content (e.g. scenario examples, scripts and models).

To get the complete content, first obtain the project repository (creating the `esmini` root folder):

* Download the source archive for the matching release (e.g. `esmini-fullsrc.zip` or the source code zip from https://github.com/esmini/esmini/releases) and extract it. This ensures alignment with the precompiled binaries and is easy for users not familiar with Git.
* Or clone the repository from GitHub: +
`git clone \https://github.com/esmini/esmini.git`

Then either build yourself, see <<Build esmini - quick guide>>, or:

. Download the pre-built binary package for your system (`esmini-bin_Windows.zip`, `esmini-bin_Linux.zip`, or `esmini-bin_macOS.zip`) from latest release:
https://github.com/esmini/esmini/releases. Copy/extract the content into the `esmini` root folder (this will populate `esmini/bin` with executables/libraries and `esmini/EnvironmentSimulator` with headers and wrappers).
. Download the complete 3D model package from https://www.dropbox.com/scl/fi/3jwz3ie6xkgpga33cbyju/models_with_lights.7z?rlkey=9obptnofidldoagn4154iyntl&st=zxoupatb&dl=1[here]. Unpack into `esmini/resources` (it should end up in a `models` subfolder, i.e. `esmini/resources/models`). These assets work on all platforms. The environment models (roads, landscape, buildings...) have been created using https://vires.mscsoftware.com/solutions/3d-environment-road-network[VIRES Road Network Editor].

Now you can run any of the complete scenarios and examples, for instance from `esmini/run/esmini` or directly from the `esmini` root folder:

``./bin/esmini --window 60 60 800 400 --osc ./resources/xosc/cut-in.xosc``

=== Build esmini - quick guide

Supported systems: Windows, Linux and Mac.

Make sure you have a C++ compiler and https://cmake.org/[CMake] installed.

On Windows https://visualstudio.microsoft.com/[Visual Studio] is recommended (Community/free version is good enough for building esmini). Make sure to check the "Desktop development with C++" package for installation, no more is needed.

On Linux, e.g. Ubuntu, some additional system tools and libraries are needed. Run the following command:

[source]
----
sudo apt install git build-essential cmake libgl1-mesa-dev libxrandr-dev libxinerama-dev libcairo2-dev
----

Now we're ready to build esmini. From esmini root folder:

[source]
----
mkdir build
cd build
cmake ..
cmake --build . --config Release --target install
----

The build process automatically downloads 3rd party library binaries and the complete 3D model package.

After successful build, the binaries will be copied into `esmini/bin` folder. Try from command line:

``./bin/esmini --window 60 60 800 400 --osc ./resources/xosc/cut-in.xosc``

That's all. Details and variants, see link:build-guide.html#_build_guide[Build guide].
